# 键盘计算器功能

键盘扩展内置了一个轻量计算器，无需切换应用即可在任意输入框中完成四则运算，计算结果直接插入到光标位置。

## 开启方式

设置 → [键盘设置](/docs/keyboard-config) → 开启「计算器」开关，键盘底部 Tab 栏会出现计算器图标。

## 按键布局

```
 (    )    C    ÷
 7    8    9    ×
 4    5    6    −
 1    2    3    +
 ±    0    .    =
```

## 支持的运算

- 加减乘除：`+` `-` `×` `÷`
- 小括号：支持嵌套，如 `(1+2)×(3+4)`
- 小数运算：结果最多保留 10 位小数，自动去除末尾多余的零
- 负数：通过 `±` 按钮切换正负号

## 使用方式

### 直接输入计算

在任意输入框中通过计算器按键输入表达式，按 `=` 后结果会追加在表达式后面：

```
输入：12+34=
结果：12+34=46
```

### 从已有文本计算

如果光标所在行已有表达式，按 `=` 会自动识别并计算：

```
光标在 "商品价格 100×3" 末尾，按 = 后变为 "商品价格 100×3=300"
```

### 清除（C 按钮）

删除当前行中从光标到上一个 `=` 之间的内容，方便重新输入。

### 正负切换（± 按钮）

切换当前输入数字的正负号。例如输入 `5` 后按 `±` 变为 `-5`。

## 主题适配

计算器按钮会跟随当前键盘皮肤主题，不同类型的按钮（数字、运算符、功能键、等号）有独立的配色方案。
