# 列表导入

列表导入，可以将CSV格式文件导入到ToMemo中，一列为一个列表，该列下的行都是一个Memo。

## 功能入口

在列表的List页面中，点击右上角「更多」按钮，再选择「导入」

<Image src="/images/list/category-import-add-entrace.png" alt="导入入口" width={300} height={600} />

## 导入文本

导入的文本来自Excel格式或者csv格式的文件，导入的文件需要符合以下格式：

- 第一行是标题，标题需要和ToMemo中的列表名称一致
- 第二行开始是列表的内容

### 逗号分隔符

```
标题,内容
标题1,内容1
标题2,内容2
标题3,内容3
```

### 制表符分隔符

```
标题	内容
标题1	内容1
标题2	内容2
标题3	内容3
```

#### 格式问题

如果导入的文本包含制表符，通过一些IM软件传输后，在手机中复制出来，制表符会变成空格，导致多列的内容变成一列。

解决办法：

- 使用苹果的接力功能，在其他设备中复制，在本机中粘贴
- 使用其他格式文本
- 使用其他跨平台剪切板

### 分号分隔符

```
标题;内容
标题1;内容1
标题2;内容2
标题3;内容3
```

### 换行内容

对于换行的内容，通过引号包裹起来，可以识别换行。

如果出现内容中有引号的情况，需要使用`\"`进行转义。

```
标题,内容
标题1,"内容1
内容2
内容3"
标题2,"内容2
内容2
内容3"
标题3,"内容3
内容2
内容3"
```
